# Font Library 1.0.0

Browse the fonts installed on your Windows PC, compare them, and keep your favorite type choices in one place.

## Highlights

- Search, preview, and filter installed fonts.
- Adjust axes on supported variable fonts.
- Compare up to four fonts with the same preview text.
- Save collections, pairings, notes, and Type Studio layouts.
- Choose a light, dark, or system theme.
- Export and import your local library data.

## Install

Download `Font-Library-Setup-1.0.0.exe` from this release and run it on Windows 10 or 11 x64. The installer creates desktop and Start menu shortcuts. Windows may warn you about the unsigned installer.

The app scans installed Windows fonts. You do not need to keep the original font download after Windows installs it. The app does not bundle font files or send your library to a server.
