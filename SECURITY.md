# Security policy

## Supported version

We review security reports for the latest release on the Releases page.

## Report a vulnerability

Open the repository's **Security** tab and use **Report a vulnerability**. That route sends your report to the maintainers without opening a public issue. Include the app version, Windows version, reproduction steps, and the impact you observed. Do not post exploit details in a public issue.

If the private reporting option is missing, contact the repository owner through the contact method on their GitHub profile. The owner should enable GitHub private vulnerability reporting before publishing this repository.
