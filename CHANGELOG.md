# Changelog

## 1.0.0 - 2026-09-28

- Browse the fonts installed for the current Windows user and the computer.
- Preview and compare fonts, including supported variable font axes.
- Save favorites, collections, pairings, notes, ratings, and layouts.
- Build samples in Type Studio with templates or a blank canvas.
- Switch between light, dark, and system themes.
- Export and import local library data.
- Install through an NSIS installer with desktop and Start menu shortcuts.
