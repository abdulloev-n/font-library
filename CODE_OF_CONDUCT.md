# Code of Conduct

We want contributors and users to feel safe asking questions and sharing work.

Treat others with respect. Discuss the change, give concrete feedback, and leave room for people with different experience levels. Do not use insults, harassment, threats, or discriminatory language. Do not publish another person's private information.

Maintainers may edit or remove comments, close discussions, or restrict participation when someone breaks these rules. If you need to report abuse, use GitHub's **Report content** option. For a private security report, follow [SECURITY.md](SECURITY.md).
